01Computer Vision · Edge Deployment · Autonomous Systems

Infrared small-target detection & tracking

Problem
A 3–7 px target, 10–16 grey levels above cloud and city clutter, has to be found on every frame.
What I did
I built a detector and tracker for 3–7 pixel aerial targets in infrared video, then ported it from Python to C++/CUDA/TensorRT: 1.7 ms per frame, 9.3× faster, with tracks identical to the prototype.

02Robotics · Signal Processing

Physics-grounded fault detection & diagnosis for a cobot

Problem
A cobot repeats one pick-and-place cycle; collisions, lost cans and friction have to be caught without labelled faults to train on.
What I did
I built an interpretable pipeline on real cobot telemetry: an unsupervised detector flags faulty cycles at AUROC 0.944 with a 1.7% false-alarm rate, and a Random Forest names the fault.

04Computer Vision · Deep Learning · Edge Deployment

Industrial defect segmentation with a C++ TensorRT app

Problem
Defects must be localised to the pixel, on parts the model never saw, without rejecting good parts.
What I did
I trained YOLO11-seg on MVTec AD to 0.82 mask mAP50, wrote the C++ TensorRT app that serves it, and found that rebalancing VisA's data lifted mask mAP50 from 0.25 to 0.41 where a bigger model did nothing.

05Signal Processing · Computer Vision

Sub-pixel Fourier registration for wafer metrology

Problem
Overlay metrology needs image shifts measured to a hundredth of a pixel.
What I did
I implemented phase correlation with matrix-multiply DFT upsampling in NumPy: 1/100-pixel shifts that match scikit-image exactly on 50 of 50 tests, benchmarked across four wafer patterns and 15–40 dB of noise.

04About

A bit about me

I'm an engineer with an M.S. in Robotics from the University of Minnesota, originally trained in mechatronics. I like the whole arc of a problem: making sense of messy data, building something that works, then making it fast and dependable enough that someone else can rely on it.

I care about evidence more than demos. I test on data a system has never seen, put the unflattering number next to the flattering one, and write down what didn't work.
