    I built an interpretable pipeline on real cobot telemetry: an unsupervised detector flags faulty cycles at AUROC 0.944 with a 1.7% false-alarm rate, and a Random Forest names the fault.

  • 04Computer Vision · Deep Learning

    Industrial defect segmentation with a C++ TensorRT app

    I trained YOLO11-seg on MVTec AD to 0.82 mask mAP50, wrote the C++ TensorRT app that serves it, and found that rebalancing VisA's data lifted mask mAP50 from 0.25 to 0.41 where a bigger model did nothing.

    Sub-pixel Fourier registration for wafer metrology

    I implemented phase correlation with matrix-multiply DFT upsampling in NumPy: 1/100-pixel shifts that match scikit-image exactly on 50 of 50 tests, benchmarked across four wafer patterns and 15–40 dB of noise.

    0.015 pxmean error on a DRAM array
